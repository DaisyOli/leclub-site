# Le Club

A responsive website for a boutique fitness and wellness studio in São Paulo, Brazil, built with Next.js, TypeScript and Tailwind CSS.

## Overview

Le Club is a premium fitness and wellness brand. The website was designed to translate its visual identity into a clear, modern and responsive digital experience.

## My role

I was responsible for implementing the interface from Figma, structuring reusable components and adapting the experience across different screen sizes.

## Main goals

- Communicate the brand's premium positioning
- Present the studio and its services clearly
- Provide a consistent responsive experience
- Translate the Figma design accurately into code

## Tech stack

- Next.js
- TypeScript
- Tailwind CSS
- Vercel

## Key decisions

- Component-based structure for easier maintenance
- Responsive layouts designed for mobile and desktop
- Reusable visual patterns to preserve brand consistency
- Attention to spacing, typography and visual hierarchy

## Status

The website is deployed and publicly available.
